# Neo Trading Tracker

Matrix/CIA-styled Android trading scanner prototype.

Features:
- Animated Matrix boot sequence and radar
- Follow arbitrary Binance USDT symbols
- Live public market-price scanning
- ENTER / WAIT / NO ACTION analytical indicator
- Ideal-bid estimate
- Live TradingView candles
- Price-alert interface

Signals are experimental analytical indicators, not guaranteed outcomes or financial advice.

GitHub Actions builds an installable debug APK on every push to main.
